# Задание 2. User story и критерии приёмки

**Сайт:** Wildberries.

Критерии приёмки сформулированы в рамках учебного задания.

## 1. Поиск товара

Как покупатель Wildberries, я хочу искать товары по названию, чтобы быстро находить нужный товар.

**Критерии приёмки:**

- На сайте доступно поле поиска товаров.
- После ввода названия товара и запуска поиска отображаются товары, соответствующие запросу.
- Поиск не зависит от регистра букв.
- Если подходящих товаров нет, отображается сообщение об отсутствии результатов.
- При нажатии на найденный товар открывается его карточка с названием, описанием и ценой.

## 2. Добавление товара в корзину

Как покупатель Wildberries, я хочу добавлять товары в корзину, чтобы собрать выбранные товары для покупки.

**Критерии приёмки:**

- В карточке товара, который есть в наличии, доступно добавление в корзину.
- Если у товара есть размеры, перед добавлением необходимо выбрать доступный размер.
- После добавления товар появляется в корзине в количестве 1 штуки.
- В корзине отображаются название, цена, количество и выбранный размер товара, если он предусмотрен.
- При добавлении другого товара ранее добавленный товар остаётся в корзине.
- Товар или размер, которого нет в наличии, нельзя добавить в корзину.
